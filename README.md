# 人体解剖生理学 · 刷题系统

一个纯前端的解剖生理学复习工具。**无需安装、无需联网、无需注册**，双击 `index.html` 即可使用，也可以部署到网上供其他人访问。

> 内置 **160 道题**，覆盖 10 个系统、**6 种题型（含看图识别题）**。

---

## 一、本地运行（最快）

1. 下载或复制整个 `anatomy-quiz` 文件夹到任意位置；
2. **双击 `index.html`**，浏览器会自动打开；
3. 建议使用 Chrome / Edge。

> ⚠️ 请双击 `index.html` 打开，**不要**单独打开 `assets` 里的文件。整个文件夹要放在一起。

**离线说明**：本项目不发起任何网络请求，断网状态下所有功能（含看图题）完全可用。

## 二、发布到网上（让别人也能用）

## 三、页面结构（共 4 个页面）

| 页面 | 文件 | 作用 |
|---|---|---|
| 今日学习 | `index.html` | 首页概览 + **按系统练习入口**：待复习数量、掌握进度、10 个系统的练习卡片、最近答题记录 |
| 题库管理 | `bank.html` | 题目增删改查、搜索筛选、导入导出 JSON 备份 |
| 刷题 | `quiz.html` | 答题主界面，支持 6 种题型和 6 种练习模式 |
| 学习统计 | `stats.html` | 章节/题型掌握度图表、错题本、数据管理 |

4 个页面共享同一份数据（浏览器 localStorage），顶部导航统一，风格一致。

## 四、六种题型

| 题型 | 出题方式 | 判分方式 |
|---|---|---|
| 单选题 | 四选一 | 点击选项即时判定 |
| 反向题 | 给功能描述，选对应结构 | 点击选项即时判定 |
| 判断题 | 判断正误 | 点击「正确 / 错误」判定 |
| 填空题 | 输入答案 | 文本比对，自动忽略空格、标点和大小写差异 |
| 名词卡 | 显示问题 → 显示答案 → 自评 | 自评「想起来了 / 没想起来」 |
| **看图题** | **显示示意图 + 箭头标注，选对应结构** | 点击选项即时判定 |

### 看图识别题说明

内置 **8 张原创 SVG 示意图**（存放在 `assets/images/`）：

| 图片 | 对应章节 | 考点 |
|---|---|---|
| `heart.svg` | 循环系统 | 心脏四腔的识别（右心室） |
| `nephron.svg` | 泌尿系统 | 肾小球的识别 |
| `neuron.svg` | 神经系统 | 髓鞘的识别 |
| `alveolus.svg` | 呼吸系统 | 肺泡与气体交换 |
| `digestive.svg` | 消化系统 | 小肠的识别 |
| `eye.svg` | 感觉器官 | 晶状体的识别 |
| `longbone.svg` | 运动系统 | 骨膜的识别 |
| `brain.svg` | 神经系统 | 小脑的识别 |

**为什么用 SVG 而不是找网图**：SVG 是矢量图，体积只有几 KB，放大不糊，断网也能显示，而且是自己画的，**没有版权问题**，答辩时可以放心讲解。

新增看图题时，在题库页选择「看图题」，填入图片路径（如 `assets/images/heart.svg`）即可，也支持填网络图片地址。

## 五、间隔重复复习算法

每道题都记录复习状态，规则如下：

| 答题结果 | 系统处理 |
|---|---|
| 答对 | 连续答对次数 +1，下次复习间隔按 **1 → 3 → 7 → 15 → 30 天** 递增 |
| 答错 | 连续答对次数清零，**立即回到今天的复习队列**，并计入错题本 |
| 连续答对 3 次 | 标记为「已掌握」 |

规则实现见 `assets/app.js` 中的 `applyResult` 函数。

## 六、六种练习模式

- **按系统练习**：首页点任意系统卡片，只刷这一章（每章 12~20 题）
- **今日复习**：只出到期的题（默认入口）
- **随机练习**：随机抽 10 题 / 任意数量
- **全部题目**：按顺序刷完整题库
- **按章节 / 按题型**：专项突破
- **错题重练**：一次重练所有错题
- **单题练习**：题库页每道题右侧的「单练」按钮

## 十、数据存储说明

- 数据保存在**本机浏览器的 localStorage**，键名为 `anatomy_quiz_state_v1`；
- 关闭浏览器、重启电脑都不会丢失；
- **部署上线后，每个访客的数据存在他自己的浏览器**，彼此独立、不互通；
- 清除浏览器数据、换浏览器、换电脑都会导致数据丢失，**建议定期到题库页导出 JSON 备份**；
- 若浏览器禁用了本地存储，系统会自动降级为「本次会话内有效」，并在统计页给出提示。

## 十一、常见问题

**Q：双击打不开 / 页面空白？**
A：确认整个文件夹完整（`assets` 目录必须在同级）。仍打不开时，可右键 `index.html` →「打开方式」→ 选择 Chrome 或 Edge。

**Q：看图题的图片显示不出来？**
A：检查 `assets/images/` 目录是否完整。在题库页编辑该题，确认「图片路径」填的是相对路径（如 `assets/images/heart.svg`）。

**Q：导入时提示「JSON 格式有误」？**
A：请粘贴数组格式的题库，或直接使用本系统导出的 `.json` 文件内容。支持 `[{...}]` 或 `{"questions":[...]}` 两种结构。

**Q：想加入自己的题目？**
A：进入「题库」页点「＋ 新增题目」，选好题型、章节、题干后填写选项并点圆点设置正确答案。

**Q：想重启学习进度？**
A：统计页底部「清空学习进度」会清空答题记录和掌握状态，**题目本身保留**；题库页「恢复内置题库」会同时清空自定义题目。

## 十三、技术说明

- 纯 HTML + CSS + 原生 JavaScript，**零依赖、零构建、零网络请求**；
- 未使用任何框架、图表库或 CDN，所有代码可逐行解释；
- 图表使用 Canvas 2D API 手动绘制，适配高分屏（devicePixelRatio）；
- 示意图使用 SVG 手写，矢量无损、体积小、离线可用；
- 全站 XSS 防护：所有用户输入内容经 `escapeHtml` 转义后再插入 DOM；
- 所有存储读写均有 try/catch 兜底，存储异常不会导致页面崩溃。
